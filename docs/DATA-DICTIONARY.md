# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

## 有功限发归因与结算（attribution-2026.11-a）

- 每个片段以辐照基线减实际为该片段待解释少发量，所有归因分项之和必须等于该值，禁止把电
  网支撑、设备故障、调度限电重复加总。
- 同一片段同时出现电网支撑与调度限电时按瀑布分摊：先用事件申报的 `active_cap_kw` 把上限
  压到 min(基线, 电网上限)，再用 `limit_kw` 压到更低者。两段增量分别计入电网支撑与可申报，
  可申报电量只含调度限额造成的增量。
- 设备故障优先认定：目标遥测状态为故障、事件申报 FAULT、或 `attribution.faults` 窗口覆盖时，
  覆盖秒数按比例计入故障。故障部分不进入可申报。
- 依据不足一律留待查，不填 0、不计入可申报：缺基线或实际、事件未申报、原因码不可识别、
  缺少可量化上限、实际高于申报上限（遥测与依据冲突）、申报上限均不低于基线、以及实际低于
  全部申报上限却无故障解释的残差。
- 片段、事件并集、全站三级核对：`allocation_balanced` 要求可申报 + 电网支撑 + 故障 + 待查
  == 已确定损失；未定片段单独展示并按秒数单列。
- 依据更正只重算受影响事件对应的片段，未受影响片段原样保留。同一依据内容哈希相同则复用、
  不新增版本；提交或切换失败整体回滚，当前指针保持旧版；历史版本只增不删。原始遥测、隔离、
  计数不因依据更正改变。
